# StudySpace 2 — библиотека RU / KZ с админ-панелью

У студентов: отдельные разделы «Русский» и «Қазақша», дисциплины, поиск и просмотр учебных материалов. У преподавателя: защищённая панель, создание дисциплин и загрузка PDF, PPTX, DOCX, DOC, PPT, MD, TXT, HTML в GitHub прямо с сайта.

## 1. Обновление существующего репозитория

Репозиторий: `olenver-04/StudySpace`.

Загрузите в **корень** репозитория файлы из ZIP (не дополнительную вложенную папку):

- `app.py`
- `github_store.py`
- `portal_logic.py`
- `catalog.json` **(он намеренно пуст — старые дисциплины исчезнут из каталога)**
- `requirements.txt`
- `assets/style.css`
- `.streamlit/config.toml`
- `.streamlit/secrets.example.toml` (это **шаблон**, без настоящих паролей)
- `.gitignore`

Подтвердите замену прежних файлов. **Старые PDF/лекции не нужно удалять**: папки `materials/uploads` могут остаться, однако в новом пустом `catalog.json` нет зарегистрированных дисциплин, поэтому старые материалы не показываются студентам. Не удаляйте другие материалы, если они вам нужны.

## 2. Настройка секретов в Streamlit Cloud — обязательна для загрузки в GitHub

Откройте [share.streamlit.io](https://share.streamlit.io), найдите своё приложение и откройте **Manage app → Settings → Secrets**. Вставьте:

```toml
ADMIN_PASSWORD = "ПРИДУМАЙ_ДЛИННЫЙ_УНИКАЛЬНЫЙ_ПАРОЛЬ"
GITHUB_TOKEN = "github_pat_ЗДЕСЬ_ВАШ_ТОКЕН"
GITHUB_REPO = "olenver-04/StudySpace"
GITHUB_BRANCH = "main"
```

Чтобы получить токен: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.

Выберите **Only select repositories → StudySpace**. Repository permissions → **Contents → Read and write**; Metadata read является стандартным. Назначьте срок действия токена. Сохраните секреты и перезапустите приложение, если настройки не применились автоматически.

**Никогда не добавляйте настоящий `GITHUB_TOKEN` или пароль администратора в GitHub.** На GitHub хранится лишь безопасный файл `.streamlit/secrets.example.toml` с примером.

## 3. Использование админ-панели

1. Откройте сайт → **Панель преподавателя** → введите `ADMIN_PASSWORD`.
2. Вкладка **Создать дисциплину**: заполните название на русском и казахском; можно указать имя папки латиницей.
3. Нажмите **Создать дисциплину**. Приложение сохранит в GitHub:
   - `materials/uploads/<id>/ru/.gitkeep`
   - `materials/uploads/<id>/kz/.gitkeep`
   - запись о предмете в `catalog.json`.
4. Во вкладке **Загрузить материалы** выберите предмет, язык, лекция/презентация, файлы; нажмите **Опубликовать материалы**. Например:
   - `materials/uploads/java/ru/lectures/Тема 1.pdf`
   - `materials/uploads/java/kz/presentations/Тақырып 1.pptx`
5. После сохранения файлов GitHub отдаёт обновлённое дерево; библиотека обновляет данные автоматически (кэш до 45 секунд, сразу после действий в админке он очищается).

Для одинаковых названий файлов замена по умолчанию запрещена: включайте «Заменять файлы» только при необходимости.

Вкладка **Мои дисциплины** позволяет скрыть дисциплину из каталога. При этом сохранённые в GitHub материалы не удаляются.

## 4. Безопасность и ограничения

- Это публичный портал; посетители могут скачать опубликованные материалы.
- Администратор получает возможность записи в репозиторий **только** при верном пароле и действующем токене, который хранится сервером в Streamlit Secrets.
- Максимум 20 МБ на файл через админ-панель. Для больших презентаций оптимизируйте медиа или храните материалы отдельно.
- PDF, Markdown, TXT и HTML просматриваются на сайте. PowerPoint и Word скачиваются; для просмотра слайдов в браузере экспортируйте PPTX в PDF.
- Для удалённых материалов используется дерево GitHub, поэтому они не зависят от временного хранилища Streamlit.
- Если `GITHUB_TOKEN` не настроен, студенты всё ещё могут читать **публичную** библиотеку, но загрузка через админ-панель отключена.

## 5. Локальный запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

Для локального администрирования можно использовать локальный `.streamlit/secrets.toml`, **не коммитя его**.
