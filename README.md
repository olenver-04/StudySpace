# StudySpace

Двуязычная (RU / KZ) библиотека учебных материалов: студенты смотрят лекции и презентации,
преподаватель загружает файлы через защищённую админку. Сайт работает на Streamlit Cloud,
а все материалы и каталог хранятся прямо в этом GitHub-репозитории.

## Что умеет

**Студентам**
- выбор языка (русский / қазақша), у каждого языка свой список предметов;
- страница предмета: лекции и презентации списком, в правильном порядке (2 перед 10);
- библиотека с поиском и фильтрами по предмету и типу;
- просмотр прямо на сайте: PDF, TXT/MD, HTML (в изолированном окне), PPTX/DOCX до 10 МБ (через просмотрщик Microsoft);
- метка «Новое» для файлов за последние 7 дней и блок «Недавно открытые»;
- QR-код и ссылка на каждый материал, большой QR для проектора;
- плакат A4 с QR-кодом на странице предмета (печать или PDF);
- поиск по всему сайту: `/` или `Ctrl K` — по названиям и по тексту внутри PDF/MD/TXT;
- отметка «Изучено» и прогресс по каждому предмету (хранится в браузере, без регистрации).

**Преподавателю** (вкладка «Преподавателю», вход по паролю)
- сводка: сколько материалов, что загружено за неделю и что требует внимания (пустые разделы, разделы без лекций);
- создать дисциплину и выбрать язык преподавания: только RU, только KZ или оба;
- загрузить файлы (PDF, PPTX, DOCX, DOC, PPT, MD, TXT, HTML, до 20 МБ);
- выбрать несколько файлов и сменить им тип «лекция ↔ презентация» или удалить;
- уведомления в Telegram о новых файлах;
- после 5 неверных паролей вход блокируется на 5 минут.

## Настройки (Streamlit Cloud → Settings → Secrets)

```toml
ADMIN_PASSWORD = "придумай-длинный-пароль"
GITHUB_TOKEN   = "github_pat_..."          # fine-grained, только этот репозиторий, Contents: Read and write
GITHUB_REPO    = "olenver-04/StudySpace"
GITHUB_BRANCH  = "main"

# необязательно
SITE_URL           = "https://адрес-сайта.streamlit.app"  # для QR-кодов и ссылок в Telegram
TELEGRAM_BOT_TOKEN = "123456:ABC..."                        # бот от @BotFather
TELEGRAM_CHAT_ID   = "-100123..."                           # или "@имя_канала"
```

Никогда не добавляйте эти значения в файлы репозитория. `.streamlit/secrets.toml` уже в `.gitignore`.

- Без `GITHUB_TOKEN` сайт работает, но админка не сможет ничего сохранять, а метки «Новое» не появятся
  (без токена GitHub даёт всего 60 запросов в час, и их бережём для каталога).
- Как получить `TELEGRAM_CHAT_ID`: админка → «Загрузить материалы» → «Уведомления в Telegram» → «Найти ID чатов».

## Где лежат файлы

```
catalog.json                                           список дисциплин (меняет админка)
materials/uploads/<дисциплина>/<ru|kz>/lectures/       лекции
materials/uploads/<дисциплина>/<ru|kz>/presentations/  презентации
```

Студентам видны только дисциплины из `catalog.json` и только на включённых для них языках.
Удалённые или перенесённые файлы можно вернуть из истории коммитов GitHub.

## Код

| Файл | Что внутри |
|---|---|
| `app.py` | все страницы, навигация, админка |
| `portal_logic.py` | разбор путей и каталога, проверка имён файлов (без Streamlit) |
| `github_store.py` | работа с GitHub API |
| `assets/style.css` | оформление (швейцарский стиль: бумага, чёрный текст, красный акцент) |
| `fulltext.py` | фоновое извлечение текста из PDF/MD/TXT для поиска → `static/fulltext.json` (создаётся сам, в git не попадает) |
| `assets/fx.js` | окно поиска, полоска загрузки, прокрутка наверх, счётчики, «Недавно открытые», «Изучено» |
| `tests/` | тесты с поддельным GitHub, секреты не нужны |

## Запуск на своём компьютере

```bash
pip install -r requirements.txt
streamlit run app.py
```

Тесты:

```bash
pip install "pytest>=8,<9"
python -m pytest
```

На GitHub тесты запускаются сами после каждой отправки (вкладка **Actions**).

## Если что-то сломалось

1. **Сайт показывает ошибку сразу после обновления** — Streamlit Cloud иногда держит старые версии файлов.
   Откройте **Manage app → ⋮ → Reboot app**.
2. **«Материалы временно недоступны»** — GitHub не ответил или закончился лимит запросов.
   Проверьте `GITHUB_TOKEN` в Secrets и обновите страницу через минуту.
3. **Красный крестик на вкладке Actions** — тесты нашли ошибку в последнем изменении: откройте запуск и посмотрите, какой тест упал.
