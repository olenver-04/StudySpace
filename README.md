# StudySpace 3.1 — выбор языка для каждой дисциплины

Это обновление существующего StudySpace 3.0. Сохраняет дизайн, админ-панель и существующие материалы, но добавляет **язык преподавания** на уровне дисциплины.

## Установка в существующий репозиторий

Замените **только следующие файлы**, сохранив вложенную структуру:

```
app.py
portal_logic.py
assets/style.css
```

В архиве обновления нет `catalog.json`, материалов или секретов: имеющиеся дисциплины и загруженные лекции не будут перезаписаны. Загрузите файлы в соответствующие пути в GitHub (`Add file` → `Upload files`), затем подтвердите коммит. Для полного пакета развёртывания есть отдельный архив.

## Как работает выбор языка

Админ-панель → «Создать дисциплину» → «Язык преподавания»:

- **🇷🇺 Только русский** — требуется русское название; создаётся `materials/uploads/<id>/ru/`. Предмет виден только студентам русского раздела.
- **🇰🇿 Тек қазақша** — требуется казахское название; создаётся `materials/uploads/<id>/kz/`. Предмет виден только студентам казахского раздела.
- **🌐 На двух языках** — требуются оба названия; создаются обе папки. Предмет виден в обоих разделах, но файлы по языкам загружаются отдельно.

Во вкладке «Загрузить материалы» теперь доступны **только языки выбранной дисциплины**. Сначала выберите дисциплину, затем язык и тип файла.

Чтобы изменить язык существующей дисциплины, откройте **«Мои дисциплины» → нужная дисциплина → «Изменить языки дисциплины» → добавить название для нового языка → «Сохранить настройки дисциплины»**. При добавлении языка создастся соответствующая папка. При отключении языка прежние файлы останутся в GitHub, но будут скрыты в каталоге студентов.

Предметы, созданные в старой версии StudySpace (без свойства `languages` в `catalog.json`), автоматически считаются **двуязычными**. Миграция вручную не нужна.

## Секреты

Настройки `ADMIN_PASSWORD`, `GITHUB_TOKEN`, `GITHUB_REPO`, `GITHUB_BRANCH` в Streamlit Cloud менять **не нужно**. Не загружайте их в репозиторий.

## Проверка

Логика языковой фильтрации и отображения протестирована; синтаксис Python и HTML проверен. Работа на опубликованном Streamlit Cloud требует проверки после коммита.
