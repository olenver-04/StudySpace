# 📚 StudySpace — библиотека для студентов

Готовый сайт на Streamlit с тёмным интерфейсом, каталогом дисциплин, поиском, фильтрами, просмотром лекций и слайдов и скачиванием файлов. Не нужны база данных, Firebase и платный API.

## 🚀 Публикация через GitHub и Streamlit Cloud

1. Создайте **новый публичный репозиторий** на GitHub, например `studyspace-college`.
2. Загрузите **содержимое** этой папки в корень репозитория (там должны находиться `app.py`, `catalog.json`, `requirements.txt`, `.streamlit/config.toml`, `materials/`, `assets/`). Для скрытой папки `.streamlit` удобнее загрузить файлы через Git или веб-интерфейс с сохранением имени папки.
3. Откройте [share.streamlit.io](https://share.streamlit.io/), выберите **Create app → Deploy a public app from GitHub**.
4. Укажите репозиторий, ветку `main` и главный файл `app.py`, затем нажмите **Deploy**.
5. Ссылка формата `https://имя-приложения.streamlit.app/` будет доступна студентам.

> Учебные файлы опубликованы открыто. Не добавляйте личные данные, оценки, пароли и иные приватные сведения.

## ➕ Добавление презентаций и лекций (без кода)

Откройте на GitHub `materials/uploads/`, затем папку предмета:

| Папка | Дисциплина |
|---|---|
| `informatics` | Информатика |
| `algorithms` | Алгоритмизация |
| `java` | Программирование на Java |
| `oop` | Объектно-ориентированное программирование |
| `databases` | Базы данных |
| `software` | Разработка программного обеспечения |
| `cms` | Системы управления контентом |

Нажмите **Add file → Upload files**, выберите свои лекции/презентации, нажмите **Commit changes**. После автоматического обновления приложения файл появится в каталоге.

**Поддерживаемые форматы:** PDF, PPTX, PPT, DOCX, DOC, MD, TXT, HTML.

- `.pdf` отображается прямо на сайте и скачивается.
- `.html` (самодостаточная презентация) отображается интерактивно на сайте и скачивается.
- `.md` и `.txt` можно читать прямо в браузере и скачивать.
- `.pptx`, `.ppt`, `.docx`, `.doc` скачиваются; встроенного просмотра для них нет. Чтобы смотреть слайды в браузере, экспортируйте PowerPoint в PDF.

Название карточки берётся из названия файла. Лучше писать название понятно: `Cikly_v_Java_ru.pdf` или `Algoritm_kz.pptx`. Суффикс `_kz` / `_kk` автоматически задаёт казахский язык, `_ru` — русский (если суффикса нет, язык RU). Для PDF лекций добавьте в имя `lekciya` или `lecture`; остальные PDF считаются презентациями.

При необходимости можно задать красивое название и описание вручную в разделах `titles` и `descriptions` файла `catalog.json` по ключу вида `java/Cikly_v_Java_ru.pdf`.

**Важно:** в бесплатной веб-загрузке GitHub есть ограничения на размер файла; для крупных материалов удобнее оптимизировать PDF или использовать отдельное файловое хранилище. Не загрузите материалы через сайт: эта версия предназначена для чтения студентами, а управление файлами производится через GitHub, чтобы изменения не пропадали.

## 🖥 Локальный запуск (необязательно)

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 🎨 Изменение оформления

- Цвета и интерфейс: `assets/style.css` и `.streamlit/config.toml`.
- Название сайта, дисциплины и пользовательские названия материалов: `catalog.json`.
- Тексты демонстрационных лекций: `.md` в `materials/uploads/`.
- Демонстрационные интерактивные презентации: `.html` в `materials/uploads/`.

## 🔒 Примечания

Проект не включает учётные записи, журнал оценок или защищённые материалы. Он публичен, и скачивать файлы могут все, у кого есть доступ к сайту или репозиторию. Для приватной библиотеки потребуется отдельная схема доступа и защищённое хранилище. Для больших видеофайлов лучше использовать видео-хостинг, а не хранение в GitHub.
