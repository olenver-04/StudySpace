StudySpace 3.5 — META College-inspired theme
============================================

Визуальный ориентир: https://eak.kz/ (META College)
Дизайн адаптирован под StudySpace; это не копирование исходного сайта и не
заявление о точном соответствии его официальным HEX-кодам.

ПАЛИТРА (цвета адаптации)
- Фирменный красный:  #BE123C
- Красный при наведении: #97112E
- Фон сайта:          #F6F7F9
- Карточки / панель:  #FFFFFF
- Основной текст:     #202630
- Вторичный текст:    #5C6673
- Границы:            #DDE1E6

ЧТО ИЗМЕНИЛОСЬ
- Белая боковая панель, красная активная кнопка
- Красный блок приветствия с белым контрастным текстом
- Светлые карточки дисциплин, лекций и статистики
- Белые поля ввода и выпадающие списки, тёмный текст
- Чёткие границы форм и информационных блоков
- Аккуратные анимации наведения без переливов/градиентов
- Уменьшенные анимации для пользователей с prefers-reduced-motion

КАК УСТАНОВИТЬ
1. В своём репозитории StudySpace на GitHub замени только:
     assets/style.css
     .streamlit/config.toml
2. Дождись обновления приложения Streamlit Cloud или перезагрузи страницу.
3. При старом оформлении принудительно обнови браузер Ctrl+F5.

НЕ ЗАТРАГИВАЕТ
- app.py
- github_store.py, portal_logic.py
- catalog.json
- материалы, дисциплины, языки, данные и GitHub-токен

Важно: точные исходные стили eak.kz не удалось получить автоматически;
стиль подобран на основе доступных сведений о META College и красной
фирменной айдентики META University. Полное визуальное совпадение с eak.kz
не утверждается.
