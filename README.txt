StudySpace 3.4 — Blood Burgundy (без градиентов)

Смена только оформления: глубокая однотонная бордовая заливка,
светлый текст, выразительные границы карточек, однотонные кнопки.
Базовая тема Streamlit приведена к той же тёмно-бордовой палитре.

Обновите ТОЛЬКО два файла в корне репозитория StudySpace:

1. assets/style.css          — заменить существующий
2. .streamlit/config.toml    — заменить существующий

В ZIP файлы уже размещены в правильных папках.
НЕ заменяйте catalog.json, github_store.py, portal_logic.py и app.py.
Ваши предметы, файлы и GitHub token в секретах останутся без изменений.

После commit Streamlit Cloud автоматически подхватит обновление.
Если цвета выглядят по-старому, обновите страницу Ctrl+F5.
