Папки создаются через админ-панель StudySpace.

После нажатия «Создать дисциплину» в GitHub появляются:
materials/uploads/<id>/ru/.gitkeep
materials/uploads/<id>/kz/.gitkeep

После загрузки материала через сайт:
materials/uploads/<id>/ru/lectures/название.md
materials/uploads/<id>/kz/presentations/название.pdf

Содержимое существующих старых папок не удаляется, но не показывается в
новом каталоге, пока дисциплина не создана через админ-панель.
