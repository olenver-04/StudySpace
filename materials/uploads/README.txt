КАК ДОБАВИТЬ МАТЕРИАЛЫ

1. Откройте папку нужной дисциплины (например java).
2. Загрузите в неё PDF, PPTX, DOCX, MD, TXT или HTML.
3. Назовите файл понятно: Cikly_v_Java_ru.pdf или Algoritm_kz.pptx.
4. Закоммитьте изменения в GitHub. Streamlit Cloud обновится автоматически.

Имя файла становится названием карточки. Суффикс _kz означает казахский язык; _ru — русский.
Для PDF по умолчанию используется тип «Презентация»; если в имени есть «lekciya» или «lecture», тип будет «Лекция».
